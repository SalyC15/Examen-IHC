# Cuestionario de satisfacción (SUS)

Aplicar después de las tareas, sin sugerir respuestas. Para cada enunciado, marcar de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo). Usar los enunciados en el mismo orden y no omitir respuestas.

1. Creo que usaría este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría ayuda de una persona con conocimientos técnicos para usar este sistema.
5. Encontré que las distintas funciones del sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en el sistema.
7. Imagino que la mayoría de las personas aprendería a usar este sistema rápidamente.
8. Encontré el sistema muy incómodo de usar.
9. Me sentí con confianza al usar el sistema.
10. Necesité aprender muchas cosas antes de poder empezar a usar el sistema.

Puntaje: para reactivos impares restar 1 a la respuesta; para pares restar la respuesta de 5; sumar y multiplicar por 2,5. Registrar solo respuestas completas. Reportar como medición descriptiva de percepción, no como prueba estadística.
