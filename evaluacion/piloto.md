# Registro del piloto P00

P00 sirve para comprobar comprensión de instrucciones, duración y hoja de observación; no representa participantes P01/P02 y no debe combinarse con resultados.

| Campo | Registro |
|---|---|
| Fecha / versión | Pendiente de ejecutar |
| Persona que pilotea | Miembro del equipo (no participante objetivo) |
| Consignas probadas | T1, T2, T3 |
| Ambigüedades detectadas | Pendiente |
| Ajustes al protocolo | Pendiente |
| Duración aproximada | Pendiente |
| Aprobación para iniciar P01/P02 | Pendiente |

No iniciar sesiones formales hasta actualizar el registro con el piloto real.
